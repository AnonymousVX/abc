2. What is transfer learning?
Ans: Transfer learning is a technique in which knowledge learned by a model on one task or dataset is reused for a different but related task.

3. Why is transfer learning useful?
Ans: It reduces training time and the amount of data required because the model already contains useful learned features.

9. What is image classification?

10. What is a pretrained model?
Ans: A pretrained model is a model whose parameters have already been learned by training on a dataset, usually a large dataset.

11. What is the difference between training from scratch and transfer learning?
Ans: Training from scratch starts with randomly initialized weights and learns features from the new dataset. Transfer learning starts with weights learned from a previous dataset and adapts them to the new task.

14. Why are ImageNet weights used?

24. What is ResNet?
Ans: ResNet stands for Residual Network. It is a deep CNN architecture that uses skip connections to make training deep networks easier.

25. What does ResNet50 mean?
Ans: ResNet50 is a ResNet architecture with approximately 50 layers, depending on the layer-counting convention.

26. What is a residual connection?
Ans: A residual connection adds the input of a block to the transformed output of that block, providing a shortcut path for information and gradients.

27. Why are skip connections used in ResNet?
Ans: They help address optimization difficulties in very deep networks and make deeper networks easier to train.

28. What is a residual block?
Ans: A residual block is a group of layers with a shortcut connection that adds the block input to its transformed output.

29. What is the role of convolutional layers?
Ans: They learn visual features such as edges, textures and more complex patterns.

30. What is the role of the final fully connected layer?

35. Can VGG16 be used for this assignment?

SECTION 4: FREEZING AND UNFREEZING LAYERS
============================================================

36. What does freezing a layer mean?
Ans: Freezing a layer means preventing its parameters from being updated during training.

37. How do we freeze all pretrained layers in PyTorch?
Ans: Set requires_grad=False for every parameter in the pretrained model.

38. What does requires_grad=False do?
Ans: It tells PyTorch not to calculate gradients for that parameter during backpropagation.

39. Why freeze pretrained layers initially?
Ans: It preserves learned ImageNet features and allows the new classifier to learn the target classes without changing the pretrained feature extractor.

40. Which layers are trained first in transfer learning?
Ans: Usually the newly added classification layer is trained first while the pretrained backbone remains frozen.

41. What is a backbone?
Ans: The backbone is the main pretrained feature-extraction part of a model.

42. What is a classification head?
Ans: The classification head is the final part of the network that maps extracted features to target class scores.

43. How do we unfreeze layers in PyTorch?
Ans: Set requires_grad=True for the parameters of the selected layers.

44. Why unfreeze only the last few layers?
Ans: Later layers learn more task-specific features, so updating them can adapt the network while retaining general features in earlier layers.

45. Should all layers always be unfrozen?
Ans: No. The choice depends on dataset size, similarity to ImageNet, computational resources and validation performance.

46. What can happen if too many layers are unfrozen on a small dataset?
Ans: The model may overfit or lose useful pretrained representations, especially if the learning rate is too high.

47. What is partial fine-tuning?
Ans: Partial fine-tuning updates only selected pretrained layers while keeping the remaining layers frozen.

48. What is full fine-tuning?
Ans: Full fine-tuning allows all pretrained model parameters to update on the target dataset.

49. Why use a smaller learning rate during fine-tuning?
Ans: Smaller updates help preserve useful pretrained features while adapting the model to the new task.

50. Which ResNet50 block is unfrozen in this practical?
Ans: The last major block, layer4. Earlier blocks layer1, layer2 and layer3 remain frozen.

51. Is unfreezing layer4 the same as unfreezing exactly the last 20 layers?
Ans: No. This practical unfreezes the layer4 module as a block. The number of individual parameterized layers is not necessarily exactly 20.

SECTION 10: IMPORTANT DIFFERENCES
============================================================

135. Transfer learning vs training from scratch

Transfer learning:
- Starts with pretrained weights.
- Reuses learned features.
- Often requires less data and training time.
- Can freeze or fine-tune selected layers.

Training from scratch:
- Starts with randomly initialized weights.
- Learns features from the target dataset.
- Usually requires more data and computation.
- All model layers are trained from the beginning.

136. Feature extraction vs fine-tuning

Feature extraction:
- Pretrained layers remain frozen.
- Only the new classifier is trained.
- Faster and less computationally expensive.

Fine-tuning:
- Selected pretrained layers are unfrozen.
- Their weights are updated on the new dataset.
- Can adapt features more closely to the target task.

137. Frozen layers vs trainable layers

Frozen layers:
- requires_grad=False.
- Their parameters are not updated by the optimizer.
- Retain pretrained weights.

Trainable layers:
- requires_grad=True.
- Gradients are calculated.
- Their parameters can be updated by the optimizer.

138. ResNet50 vs VGG16

ResNet50:
- Uses residual connections.
- Supports deeper networks.
- Helps optimization through shortcut connections.

VGG16:
- Uses a sequential architecture.
- Commonly uses 3 x 3 convolution filters.
- Has a large fully connected classifier in its original form.

139. Training mode vs evaluation mode

Training mode:
- Set using model.train().
- Used during model training.
- Dropout and batch normalization use training behaviour.

Evaluation mode:
- Set using model.eval().
- Used during testing and prediction.
- Dropout and batch normalization use evaluation behaviour.
