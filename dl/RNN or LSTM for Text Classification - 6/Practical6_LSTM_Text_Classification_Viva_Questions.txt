============================================================
SECTION 1: BASICS OF TEXT CLASSIFICATION
============================================================

1. What is text classification?
Text classification is the process of assigning a category or label to a text. In this practical, movie reviews are classified as positive or negative.

2. What is sentiment analysis?
Sentiment analysis identifies the opinion or emotion expressed in text, such as positive, negative, or neutral.

3. What is the objective of this practical?
To implement an LSTM model using PyTorch for binary sentiment classification on the IMDB movie review dataset, evaluate its accuracy, and visualize example predictions.

4. What is the IMDB dataset?
It is a movie-review dataset containing reviews labelled as positive or negative. The standard dataset has 25,000 training reviews and 25,000 test reviews.

5. What does binary classification mean?
It means predicting one of two possible classes. Here, class 0 means negative and class 1 means positive.

6. What is NLP?
Natural Language Processing is a field of AI that enables computers to process and understand human language.

7. Why do we need text preprocessing?
Machine-learning models operate on numerical data. Text must be cleaned or tokenized and converted into numerical representations before it can be processed.

8. What is a review?
A review is a text written by a user expressing an opinion about a movie.

9. What are the input and output of this practical?
The input is a movie review represented as a sequence of token IDs. The output is a probability or predicted class indicating positive or negative sentiment.

10. What is a label?
A label is the correct target category associated with a data sample. In this practical, 0 represents negative and 1 represents positive.

SECTION 3: TOKENIZATION AND VOCABULARY
============================================================

26. What is tokenization?
Tokenization is the process of splitting text into smaller units, such as words.

27. What is a token?
A token is an individual unit of text, such as a word or punctuation mark.

28. What does the tokenize() function do in our code?
It converts text to lowercase and extracts word-like tokens using a regular expression.

29. Why do we convert text to lowercase?
To treat words with different capitalization as the same token, reducing unnecessary vocabulary differences.

30. What is a vocabulary?
A vocabulary is a collection of unique tokens mapped to integer IDs.

31. Why do we convert words into numbers?
Neural networks operate on numerical tensors, not raw text strings.

32. What is Counter?
Counter is a Python collection used to count how frequently each token appears.

33. What is MAX_VOCAB_SIZE?
It is the maximum number of tokens retained in the vocabulary, including special tokens.

34. What is <PAD>?
It is a special token with ID 0 used to make sequences in a batch the same length.

35. What is <UNK>?
It is a special token used for words that are not present in the vocabulary. In our code it has ID 1.

36. What does vocab.get(word, 1) mean?
It returns the word's vocabulary ID. If the word is unknown, it returns ID 1, which represents <UNK>.

37. What is MAX_LENGTH?
It is the maximum number of tokens retained from each review. In our code it is 200.

38. Why do we limit review length?
It controls memory use and computation time and gives batches a manageable sequence length.

39. What happens if a review contains more than 200 tokens?
The code truncates it to the first 200 tokens.

40. What happens if a review is empty after tokenization?
The code inserts the unknown-token ID so the sequence is not empty.

41. What is a PyTorch Dataset?
A Dataset is a class that defines how to access individual samples and how many samples are available.

42. Why do we create a custom IMDBDataset class?
Because text reviews need to be tokenized and converted into tensors before being supplied to the model.

43. What is __init__()?
It initializes the Dataset object and stores the input data.

44. What does __len__() do?
It returns the number of samples in the dataset.

45. What does __getitem__() do?
It returns one review and its corresponding label for a given index.

46. What is a tensor?
A tensor is a multidimensional numerical data structure used by PyTorch.

47. Why is the text tensor dtype torch.long?
Embedding layers require integer token indices, which are represented using long integer tensors.

48. Why is the label dtype torch.float32?
The binary loss function used in this practical expects floating-point target values.

49. What is DataLoader?
DataLoader loads data in batches and can shuffle samples and apply a custom batch-processing function.

50. What is batch size?
It is the number of samples processed together in one training iteration. Our code uses 64.

51. What does shuffle=True do?
It randomly changes the order of training samples each epoch.

52. Why is shuffle=False used for validation and testing?
Shuffling is not necessary for evaluation and keeping order stable makes evaluation easier to reproduce.

53. What is collate_fn?
It is a custom function passed to DataLoader to combine individual samples into a batch.

54. Why do we need collate_batch()?
Reviews have different lengths. The function pads them to a common length and stacks their labels.

55. What is padding?
Padding adds special values to shorter sequences so all sequences in a batch have equal length.

56. What does pad_sequence() do?
It pads variable-length tensors to the length of the longest sequence in the batch.

57. What does batch_first=True mean?
It makes the batch dimension the first dimension. Text batches have shape (batch size, sequence length).

58. What are sequence lengths?
They record the actual number of tokens in each review before padding.

59. Why do we return lengths from collate_batch()?
The LSTM uses them to ignore padding when processing each review through pack_padded_sequence().

SECTION 5: LSTM AND NEURAL NETWORK
============================================================

60. What is a neural network?
A neural network is a computational model made of connected layers that learn patterns from data.

61. What is RNN?
A Recurrent Neural Network is a neural network designed to process sequential data by maintaining information from previous steps.

62. What is LSTM?
Long Short-Term Memory is a type of RNN designed to learn long-term dependencies and reduce the vanishing-gradient problem.

63. Why do we use LSTM for text classification?
Words occur in sequence, and LSTM can learn contextual information from earlier words while processing a review.

64. What is the difference between RNN and LSTM?
A basic RNN has a simpler recurrent structure. LSTM has a memory cell and gates that help control information flow over longer sequences.

65. What are the three main gates in an LSTM?
Forget gate, input gate, and output gate.

66. What does the forget gate do?
It controls which information from the previous cell state should be discarded.

67. What does the input gate do?
It controls which new information should be added to the cell state.

68. What does the output gate do?
It controls which information from the cell state is used to produce the hidden state.

69. What is the cell state?
It is the internal memory pathway that carries information through the LSTM sequence.

70. What is the hidden state?
It is the output representation passed through the sequence and used to represent the processed information.

71. What is an embedding layer?
It converts each integer token ID into a trainable dense vector.

72. Why do we use nn.Embedding?
It learns vector representations of words instead of treating word IDs as meaningful numeric quantities.

73. What is EMBEDDING_DIM?
It is the number of values in each word embedding vector. Our code uses 128.

74. What is HIDDEN_DIM?
It is the number of hidden units in the LSTM. Our code uses 64.

75. What does batch_first=True mean in nn.LSTM?
It means the input tensor is arranged as batch, sequence length, and feature dimensions.

76. What is a fully connected layer?
A layer in which each output neuron is connected to all input features.

77. Why does our final Linear layer have one output?
Because we are predicting one binary sentiment score for each review.

78. What is sigmoid?
Sigmoid maps a real-valued number to a value between 0 and 1.

79. Why is sigmoid used for binary classification?
It converts the model output into a probability-like score for the positive class.

80. What is the decision threshold?
It is the cutoff used to convert the predicted score into a class. Our code uses 0.5.

81. How is the final sentiment predicted?
A score of at least 0.5 is classified as positive; a score below 0.5 is classified as negative.

82. What does nn.Module do?
It is the base class for building custom PyTorch neural network models.

83. Why do we use super().__init__()?
It initializes the parent nn.Module class so PyTorch can register model layers and parameters.

84. What does the forward() method do?
It defines how input data passes through the model to produce an output.

85. What is pack_padded_sequence()?
It packs padded sequences so the LSTM can process the actual sequence lengths without treating padding as real review content.

86. Why do we use enforce_sorted=False?
It allows sequences to be supplied without manually sorting them by length.

SECTION 6: TRAINING AND OPTIMIZATION
============================================================

87. What is model training?
Training is the process of adjusting model parameters to reduce prediction error.

88. What is an epoch?
One complete pass through the entire training dataset.

89. What is an iteration?
One update step using a batch of training samples.

90. What is a loss function?
It measures the difference between model predictions and actual target values.

91. Which loss function is used in our final code?
BCEWithLogitsLoss.

92. Why do we use BCEWithLogitsLoss?
It combines sigmoid and binary cross-entropy in a numerically stable operation.

93. Should we apply sigmoid before BCEWithLogitsLoss?
No. BCEWithLogitsLoss expects raw logits and applies the sigmoid operation internally.

94. What is an optimizer?
An optimizer updates model parameters using gradients calculated during backpropagation.

95. Which optimizer is used?
Adam optimizer.

96. What is Adam?
Adam is an optimization algorithm that adapts learning rates for model parameters using estimates of gradient averages.

97. What is learning rate?
It controls the size of parameter updates during optimization. Our code uses 0.001.

98. What does optimizer.zero_grad() do?
It clears gradients from the previous iteration before calculating new gradients.

99. What does loss.backward() do?
It calculates gradients of the loss with respect to model parameters using backpropagation.

100. What does optimizer.step() do?
It updates the model parameters using the calculated gradients.

101. What does model.train() do?
It puts the model into training mode.

102. What does model.eval() do?
It puts the model into evaluation mode.

103. What does torch.no_grad() do?
It disables gradient tracking, saving memory and computation during evaluation.

104. What is backpropagation?
It calculates gradients by propagating the loss information backward through the network.

105. What is overfitting?
Overfitting occurs when a model learns training examples too specifically and performs poorly on unseen data.

106. How can overfitting be reduced?
Use more data, dropout, regularization, early stopping, or other suitable techniques.

SECTION 7: EVALUATION AND VISUALIZATION
============================================================

107. What is accuracy?
Accuracy is the percentage of predictions that are correct.

108. What is the formula for accuracy?
Accuracy = (Number of correct predictions / Total predictions) × 100.

109. What is training accuracy?
It is the percentage of correct predictions on the training dataset.

110. What is validation accuracy?
It measures performance on validation data that is not used for gradient updates.

111. What is test accuracy?
It measures final model performance on the separate test dataset.

112. Why do we plot accuracy?
To observe how model performance changes across training epochs.

113. Why do we plot training loss?
To monitor whether the model's prediction error decreases during training.

114. What does a decreasing training loss generally indicate?
It generally indicates that the model is fitting the training data better.

115. What does a large gap between training and validation accuracy suggest?
It may indicate overfitting.

116. What is model evaluation?
It is the process of measuring performance on data not used to update the model.

117. Why do we visualize example predictions?
To understand how the model classifies individual reviews and compare predictions with actual labels.

118. What does prediction confidence mean in our example?
It is the sigmoid-transformed output score. It indicates the model's estimated positive-class probability, not a guarantee that the prediction is correct.

119. What does the red bar represent in the prediction chart?
A predicted positive probability below 0.5, so the review is classified as negative.

120. What does the green bar represent?
A predicted positive probability of at least 0.5, so the review is classified as positive.

121. What is a confusion matrix?
A table showing true positives, true negatives, false positives, and false negatives.

122. What is precision?
Precision is the proportion of predicted positive examples that are actually positive.

123. What is recall?
Recall is the proportion of actual positive examples that are correctly identified.

124. What is F1-score?
It is the harmonic mean of precision and recall.

SECTION 10: IMPORTANT CONCEPTUAL QUESTIONS
============================================================

156. Why is LSTM suitable for sequential data?
It processes elements in order and maintains information through its hidden and cell states.

157. What is the vanishing gradient problem?
It occurs when gradients become extremely small during backpropagation, making earlier layers or time steps difficult to train.

158. How does LSTM help with vanishing gradients?
Its gated cell-state pathway helps preserve information and gradients over longer sequences.

159. Can LSTM classify positive and negative reviews?
Yes. It learns patterns in review sequences and predicts one of two sentiment classes.

160. Is this a supervised learning problem?
Yes. The model learns from reviews that have known sentiment labels.

161. What is supervised learning?
It is a machine-learning approach in which a model learns from input examples paired with target labels.

162. What is an embedding vector?
It is a numerical representation of a token in a continuous vector space.

163. Does the embedding layer learn during training?
Yes. Its embedding weights are trainable parameters updated through backpropagation.

164. Why not use only a fully connected layer on word IDs?
Word IDs are arbitrary identifiers and do not express word meaning or sequence relationships. Embeddings and LSTM provide more suitable representations.

165. What is sequence modelling?
It is the process of learning patterns in ordered data such as text, speech, or time series.

166. What is binary cross-entropy?
It measures the error between predicted probabilities and binary target labels.

167. What is a logit?
A logit is the raw model output before applying sigmoid.

168. What is the relationship between logit zero and probability 0.5?
Sigmoid(0) equals 0.5, so zero is the decision boundary for a 0.5 threshold.

169. What happens if the vocabulary size is too small?
More words become unknown tokens, which may remove useful information.

170. What happens if the vocabulary size is too large?
The embedding layer becomes larger and needs more memory and training.

171. What happens if MAX_LENGTH is too small?
Important words near the end of longer reviews may be truncated.

172. What happens if MAX_LENGTH is too large?
Training can require more memory and computation.

173. Why use padding_idx=0 in nn.Embedding?
It identifies the padding token so its embedding is not updated like normal word embeddings.

174. What is a limitation of this simple sentiment model?
It uses a limited vocabulary and a basic word-tokenization approach, so it may not understand all context, sarcasm, or complex language.

175. Can this model be used for multi-class classification?
Yes, but the output layer, labels, and loss function must be adapted for more than two classes.
