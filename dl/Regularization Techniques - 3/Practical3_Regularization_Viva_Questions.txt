============================================================ SECTION 1:
AIM AND BASIC CONCEPTS
============================================================

Q1. What is the aim of this practical? Answer: The aim is to experiment
with regularization techniques by training a neural network without
regularization, with L2 regularization, and with L2 regularization
combined with Dropout. Their performance is evaluated and compared, and
training/validation metrics are visualized.

Q2. What is regularization in machine learning? Answer: Regularization
is a set of techniques used to reduce overfitting by discouraging a
model from becoming unnecessarily complex. It helps a model generalize
better to unseen data.

Q3. What is overfitting? Answer: Overfitting occurs when a model learns
the training data too closely, including noise or accidental patterns.
It performs well on training data but poorly on unseen or validation
data.

Q4. What is underfitting? Answer: Underfitting occurs when a model is
too simple or insufficiently trained to learn the underlying patterns.
It performs poorly on both training and validation data.

Q5. What is generalization? Answer: Generalization is the ability of a
trained model to make accurate predictions on new data that it did not
see during training.

Q6. Why do we need regularization? Answer: We use regularization to
control model complexity, reduce overfitting, and improve performance on
unseen data.

Q7. Does regularization always increase accuracy? Answer:
No. Regularization can sometimes reduce training accuracy because it
restricts learning. Its purpose is to improve generalization, not
necessarily to maximize training accuracy.

Q8. What is the difference between training performance and validation
performance? Answer: Training performance is measured on data used to
update model weights. Validation performance is measured on a separate
portion of data that is not used for weight updates and helps monitor
generalization during training.

============================================================ SECTION 2:
DATASET AND PREPROCESSING
============================================================

Q9. Which dataset is used in this practical? Answer: The MNIST
handwritten digit dataset.

Q10. What is MNIST? Answer: MNIST is a standard dataset of handwritten
digits from 0 to 9. It contains 28 x 28 grayscale images and their
corresponding digit labels.

Q11. What is the shape of each MNIST image? Answer: Each image has a
height of 28 pixels and a width of 28 pixels, so its shape is 28 x 28.

Q12. How many classes are present in MNIST? Answer: There are 10
classes, representing digits 0 through 9.

Q13. What does mnist.load_data() return? Answer: It returns two pairs:
(X_train, y_train) for training and (X_test, y_test) for testing.

Q14. What are X_train and y_train? Answer: X_train contains training
images, while y_train contains the correct digit labels for those
images.

Q15. What are X_test and y_test? Answer: X_test contains test images,
and y_test contains their correct digit labels. They are used to
evaluate the trained model on unseen data.

Q16. Why do we divide image values by 255.0? Answer: An 8-bit grayscale
pixel ranges from 0 to 255. Dividing by 255 scales pixel values to the
range 0 to 1, which usually makes neural-network training more stable
and convenient.

Q17. What is normalization? Answer: Normalization is the process of
scaling input values to a common range or scale. In this practical,
pixel values are scaled from 0–255 to 0–1.

Q18. What does X_train.shape show? Answer: It shows the dimensions of
the training image array, including the number of images and the 28 x 28
dimensions of each image.

Q19. Why is the test set not used during model.fit()? Answer: The test
set should remain separate until final evaluation. Using it repeatedly
during training or model selection can lead to biased evaluation.

Q20. What is validation_split=0.2? Answer: It reserves 20% of the
supplied training data for validation. The remaining 80% is used to
update the model weights.

============================================================ SECTION 3:
MODEL ARCHITECTURE
============================================================

Q21. Which deep-learning framework is used? Answer: TensorFlow, using
its Keras API.

Q22. What is Keras? Answer: Keras is a high-level deep-learning API that
makes it easier to build, train, and evaluate neural networks.

Q23. What is a Sequential model? Answer: A Sequential model is a linear
stack of layers. Each layer passes its output to the next layer.

Q24. What is a Dense layer? Answer: A Dense layer is a fully connected
neural-network layer in which each neuron receives input from every
output in the previous layer.

Q25. What is Flatten? Answer: Flatten converts a multidimensional input
into a one-dimensional vector. Here it converts a 28 x 28 image into a
vector of 784 values.

Q26. Why is Flatten used in this practical? Answer: The Dense layers
expect a one-dimensional feature vector per example. Flatten converts
each 28 x 28 image into 784 input values.

Q27. How many neurons are in the first hidden Dense layer? Answer: 128
neurons.

Q28. How many neurons are in the second hidden Dense layer? Answer: 64
neurons.

Q29. What is an activation function? Answer: An activation function
transforms a neuron’s weighted input and helps a neural network learn
nonlinear relationships.

Q30. Which activation function is used in the hidden layers? Answer:
ReLU.

Q31. What is ReLU? Answer: ReLU stands for Rectified Linear Unit. It
returns max(0, x): negative inputs become zero and positive inputs
remain unchanged.

Q32. Why is ReLU commonly used in hidden layers? Answer: It is
computationally simple and introduces nonlinearity, helping neural
networks learn complex patterns.

Q33. Which activation function is used in the output layer? Answer:
Softmax.

Q34. Why is Softmax used in the output layer? Answer: This is a 10-class
classification problem. Softmax converts output scores into class
probabilities that sum to approximately 1.

Q35. Why does the output layer contain 10 neurons? Answer: There are 10
possible digit classes, from 0 to 9, so one output neuron represents
each class.

Q36. What does the model predict? Answer: It predicts the probability of
the input image belonging to each digit class. The class with the
highest probability is the predicted digit.

Q38. Which optimizer is used? Answer: Adam.

Q39. What is an optimizer? Answer: An optimizer updates the model’s
trainable weights to reduce the loss function during training.

Q40. What is Adam? Answer: Adam stands for Adaptive Moment Estimation.
It is an optimization algorithm that adapts learning rates for model
parameters using estimates of first and second moments of gradients.

Q41. Which loss function is used? Answer:
sparse_categorical_crossentropy.

Q42. Why is sparse_categorical_crossentropy used? Answer: The task has
multiple mutually exclusive classes, and the labels are integer class
IDs (0 to 9), rather than one-hot encoded vectors. This makes sparse
categorical cross-entropy appropriate.

Q43. What is categorical cross-entropy? Answer: It measures the
difference between the true class distribution and the predicted class
probabilities. It is commonly used for multi-class classification with
one-hot encoded labels.

Q44. What is the difference between categorical and sparse categorical
cross-entropy? Answer: Categorical cross-entropy expects labels in
one-hot encoded form. Sparse categorical cross-entropy expects integer
class labels.

Q45. What does metrics=[‘accuracy’] mean? Answer: It tells Keras to
report classification accuracy during training, validation, and
evaluation.

Q46. What is an epoch? Answer: One epoch means the model has processed
every example in the training portion once.

Q47. How many epochs are used in this practical? Answer: 15 epochs for
each of the three models.

Q48. What is batch_size=128? Answer: The model processes 128 training
examples in each batch before performing a weight update.

Q49. What is the difference between an epoch and a batch? Answer: An
epoch is one complete pass through the training data. A batch is a
smaller group of examples processed in one training step.

Q50. What does model.fit() do? Answer: It trains the model using the
supplied training data and labels, for the specified number of epochs
and batch size.

Q51. What does verbose=1 mean? Answer: It displays a progress bar and

============================================================ SECTION 5:
L2 REGULARIZATION
============================================================

Q54. What is L2 regularization? Answer: L2 regularization adds a penalty
based on the squared values of model weights to the original loss
function. It discourages excessively large weights.

Q55. What is the formula for L2 regularization? Answer: A common form
is: Total Loss = Original Loss + lambda * sum(w_i^2) Here, w_i
represents model weights and lambda controls the regularization
strength. Framework implementations may use a scaling convention for the
penalty.

Q56. Which L2 value is used in this practical? Answer: The code uses
l2(0.001), so the regularization coefficient is 0.001.

Q57. What does l2(0.001) mean in Keras? Answer: It creates an L2
regularizer with a coefficient of 0.001. The regularization penalty is
added to the training objective for the layer’s kernel weights.

Q58. Where is L2 regularization applied in model2? Answer: It is applied
to the kernel weights of the two hidden Dense layers with 128 and 64
neurons.

Q59. Is L2 applied to the output Dense layer in model2? Answer: No. The
output Dense layer does not specify kernel_regularizer in the notebook.

Q60. What is a weight in a neural network? Answer: A weight is a
learnable numerical parameter that controls the strength of the
connection between neurons.

Q61. Why does L2 discourage large weights? Answer: Squaring the weights
makes large weight values contribute a larger penalty. The optimizer is
therefore encouraged to keep weights smaller, all else being equal.

Q62. What is lambda in L2 regularization? Answer: Lambda is the
regularization-strength coefficient. A larger value generally applies a
stronger penalty, while a smaller value applies a weaker penalty.

Q63. What happens if the L2 coefficient is too high? Answer: The model
may be overly constrained and may underfit, resulting in poor training
and validation performance.

Q64. What happens if the L2 coefficient is too low? Answer: The penalty
may be too weak to meaningfully reduce overfitting.

Q65. Does L2 force weights to become exactly zero? Answer: Usually no.
L2 tends to shrink weights toward zero, but unlike L1 regularization it
does not generally produce sparse weights with many exact zeros.

Q66. What is weight decay? Answer: Weight decay refers to shrinking
model weights during optimization. It is closely related to L2
regularization, although implementation details can make the two
different for adaptive optimizers such as Adam.

============================================================ SECTION 6:
DROPOUT ============================================================

Q67. What is Dropout? Answer: Dropout is a regularization technique that
randomly sets a fraction of layer outputs to zero during training. This
reduces reliance on particular neurons and can help reduce overfitting.

Q68. Which Dropout rates are used in this practical? Answer: The
notebook uses Dropout(0.5) after the 128-neuron Dense layer and
Dropout(0.3) after the 64-neuron Dense layer.

Q69. What does Dropout(0.5) mean? Answer: During training, approximately
50% of the outputs entering that Dropout layer are randomly set to zero
for each training step.

Q70. What does Dropout(0.3) mean? Answer: During training, approximately
30% of the outputs entering that Dropout layer are randomly set to zero.

Q71. Does Dropout permanently remove neurons? Answer: No. Dropout does
not permanently delete neurons or weights. It temporarily masks
activations during training. At inference time, Dropout is inactive and
the full network is used with the appropriate scaling handled by Keras.

Q72. Is Dropout active during testing? Answer: No. In normal Keras
evaluation and inference, Dropout is inactive.

Q73. Why is Dropout used? Answer: It reduces co-adaptation between
neurons and encourages the network to learn more robust features, which
can reduce overfitting.

Q74. What happens if the Dropout rate is too high? Answer: Too much
information may be removed during training, making learning difficult
and causing underfitting.

Q75. What happens if the Dropout rate is zero? Answer: No outputs are
dropped, so the Dropout layer has no regularization effect.

Q76. What is the difference between L2 and Dropout? Answer: L2 adds a
penalty for large weights to the loss function. Dropout randomly masks
layer activations during training. Both aim to reduce overfitting but
work differently.

============================================================ SECTION 8:
EVALUATION AND COMPARISON
============================================================

Q86. What does model.evaluate() do? Answer: It evaluates a trained model
on the supplied data and returns the configured loss and metric values.

Q87. Which data is used for final evaluation? Answer: The notebook uses
X_test and y_test, the held-out MNIST test set.

Q88. What does loss1, acc1 = model1.evaluate(…) mean? Answer: It stores
the test loss in loss1 and the test accuracy in acc1 for model1. The
same approach is used for model2 and model3.

Q89. What is accuracy? Answer: Accuracy is the fraction of predictions
that are correct. It is calculated as correct predictions divided by
total predictions.

Q90. What is loss? Answer: Loss is a numerical measure of how far the
model’s predictions are from the target labels according to the selected
loss function. Lower loss is generally better for the same evaluation
setup.

Q91. Is higher accuracy always enough to choose a model? Answer: No. We
should also consider validation/test loss, the gap between training and
validation performance, stability, and the practical cost of the model.

Q92. How can we identify overfitting from learning curves? Answer: A
common sign is training loss continuing to decrease while validation
loss stops decreasing or starts increasing. Training accuracy may
continue increasing while validation accuracy stops improving.

Q93. What does it mean if training and validation accuracy are both low?
Answer: It may indicate underfitting, insufficient training, poor model
capacity, or problems with the data or training setup.

Q94. What does it mean if training accuracy is high but validation
accuracy is much lower? Answer: It suggests the model may be overfitting
the training data.

Q95. What should we expect regularization to do to training accuracy?
Answer: It may lower training accuracy because the model is constrained
or randomly drops activations during training. That is not necessarily a
problem if validation or test performance improves.

============================================================ SECTION 11:
IMPORTANT DIFFERENCES
============================================================

Q125. Difference between L1 and L2 regularization? Answer: L1 adds a
penalty based on the sum of absolute weight values and can encourage
sparse weights. L2 adds a penalty based on the sum of squared weights
and tends to shrink weights toward zero.

Q126. Difference between Dropout and data augmentation? Answer: Dropout
randomly masks activations inside the network during training. Data
augmentation creates modified training examples, such as rotated or
shifted images, to increase input diversity.

Q127. Difference between validation data and test data? Answer:
Validation data is used during model development to monitor performance
and guide choices. Test data is held back for final evaluation.

Q128. Difference between parameters and hyperparameters? Answer:
Parameters are learned from data, such as weights and biases.
Hyperparameters are settings chosen before or during model development,
such as epochs, batch size, L2 coefficient, and Dropout rate.

Q129. Difference between classification and regression? Answer:
Classification predicts a category or class, such as a digit from 0 to
9. Regression predicts a continuous numerical value.

Q130. Is MNIST a classification or regression problem? Answer: It is a
multi-class classification problem because the model predicts one of ten
digit categories.

validation loss.
